Zenith Dental Clinic Website 🦷

A professional, responsive, and fully functional single-page website designed for Zenith Dental Clinic. This project demonstrates a modern approach to healthcare web design, focusing on patient trust, ease of booking, and mobile responsiveness.

🎨 Design Philosophy

The design utilizes a "Soft Teal & Clinical White" palette to evoke feelings of cleanliness, calm, and professionalism. The UI features rounded corners and soft shadows to create a friendly, non-threatening environment for dental patients.

✨ Key Features

Responsive Navigation: Sticky navbar with a smooth mobile hamburger menu.

Split Hero Section: High-converting layout with "Book Appointment" CTAs and trust indicators.

Floating Info Cards: Unique overlapping layout for Hours, Location, and Emergency contacts.

Interactive Booking Modal: Functional appointment form with validation and loading states.

Trust Building Sections:

Meet the Team: Grid layout for staff profiles.

Smile Gallery: "Before & After" visuals with hover effects.

Insurance Partners: Logo strip of accepted providers.

FAQ Accordion: JavaScript-powered slide-down answers.

Tech Stack: Pure HTML5, Tailwind CSS (via CDN), and Vanilla JavaScript.
